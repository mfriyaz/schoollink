# SchoolLink

SchoolLink is a cloud-based School Management and Communication Platform designed for small and medium-sized schools.

## Vision

To simplify communication between schools, teachers, parents, and students through a secure and easy-to-use platform.

## Phase 1 Features

- User Authentication
- Homework Management
- Parent Acknowledgement
- Announcements
- Reports

## Technology Stack

Frontend
- React

Backend
- Node.js
- Express.js

Database
- PostgreSQL

Infrastructure
- Docker
- Terraform
- Ansible
