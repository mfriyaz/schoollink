# SchoolLink Database Design

## Version
1.0

## Purpose

This document describes the database schema used by SchoolLink Version 1.0.

The database is designed to support:

- Authentication
- Student Management
- Teacher Management
- Guardian Management
- Posts (Homework, Announcements, Reminders)
- Parent Acknowledgements

The design should remain simple while allowing future expansion for attendance, examinations, fee management, and multi-school support.
